# 🔑 Custom Password Generator Application

A robust, highly interactive, and client-side Password Generator web application. Built strictly using vanilla web standards, this tool allows users to safely generate cryptographically random, custom-length secure passwords tailored specifically to dynamic modern security frameworks and compliance standards.

---

## Features

* **Live-Adjustable Length:** Features a customized dynamic range slider that allows seamless length alterations between 0 and 20 characters with instant, live text rendering updates.
* **Granular Complexity Control:** Toggle options to aggregate or isolate specific character matrices including Uppercase Letters, Lowercase Letters, Numeric Sets, and Special Symbolic Characters.
* **Instant Clipboard Integration:** Integrated with the modern web Clipboard API to execute secure, single-click copying routines complete with explicit visual user alerts.
* **Defensive Input Validation:** Native edge-case handling built directly into the codebase to validate configurations and warn users if generation is triggered with zero parameters selected.

---

## Technologies Used

* **HTML5:** Structuring interactive control clusters, range parameters, and native binary toggle state check-boxes.
* **CSS3:** Sleek dark-mode aesthetic modeling a terminal-inspired developer theme, featuring localized grid mappings and interactive active-state transitions.
* **JavaScript (ES6+):** Core logic managing targeted array concatenations, deterministic randomization routines via `Math.random()`, conditional filter mapping, and browser API data transport.

---

## File Structure

* `index.html` - Architecture for user options, input sliders, password outputs, and copy controls.
* `style.css` - Modern styling rules, color palette declaration, container responsive limits, and interface layouts.
* `script.js` - Logic controlling dynamic array generation, operational loops, data verification, and copy processes.

---

##  How to Run the Project Local

1. **Clone or download** this repository onto your operating system.
2. Directly open the `index.html` file using your web browser of choice.
3. Define your target security constraints, adjust length parameters, and instantly generate production-ready secure credentials.
